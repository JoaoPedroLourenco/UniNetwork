# Bem-vindo(a) ao UniNetwork!

# Visão Geral

### A UniNetwork é uma rede social projetada para estudantes universitários, com o objetivo de promover a interação entre eles. A plataforma permite que os usuários compartilhem textos e fotos relacionados à vida acadêmica, facilitando a troca de experiências, ideias e dicas. Este ambiente virtual conecta alunos de diferentes cursos e instituições, fortalecendo a comunidade universitária.

### O projeto foi desenvolvido para o bootcamp Jovem Programador 2024 da Unimar :)

# Requisitos de Instalação

## Passo 1: Clonar o Repositório

Execute o seguinte comando no terminal para clonar o projeto:

`git clone https://github.com/JoaoPedroLourenco/UniNetwork/`

## Passo 2: Acessar a Pasta do Projeto

Entre no diretório do projeto:

`cd UniNetwork`

## Passo 3: Instalar Dependências

Instale as dependências necessárias:

`npm install`

## Passo 4: Executar o Projeto

Inicie o servidor de desenvolvimento:

`npm run dev`

# Tecnologias Utilizadas

## React: Biblioteca para criação da interface de usuário.

## Firebase:

<ul>
  <li>Firestore: Banco de dados em tempo real para armazenamento de postagens e perfis.</li>
  
  <li>Firebase Storage: Armazenamento de fotos compartilhadas pelos usuários.</li>
  
  <li>Autenticação Firebase: Sistema de login para acesso à plataforma.</li>
</ul>






# Contribuição é sempre bem-vinda!

Se você deseja contribuir para o projeto, siga os passos abaixo:

Realize um fork do repositório.

Crie uma branch para sua funcionalidade:

`git checkout -b minha-funcionalidade`

Implemente as mudanças desejadas.

Envie suas alterações:

`git push origin minha-funcionalidade`

Abra um Pull Request no repositório original.
